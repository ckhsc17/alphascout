# 資料來源

公開服務會透過網站和 MCP 再散布資料，所以選擇來源時**授權比免費更重要**。原則：優先使用官方開放資料。

## 台股

| 來源                                  | 資料                                                 | 頻率       | 備註                                                   |
| ------------------------------------- | ---------------------------------------------------- | ---------- | ------------------------------------------------------ |
| **TWSE**（證交所 OpenAPI / 網站資料） | 上市證券清單、日成交、本益比／殖利率、三大法人買賣超 | 每日盤後   | 政府開放資料                                           |
| **TPEx**（櫃買中心）                  | 上櫃的同類資料                                       | 每日盤後   | 同上                                                   |
| **MOPS**（公開資訊觀測站）            | 月營收、內部人持股轉讓申報、財報                     | 每月／事件 | 格式較雜，需要清洗                                     |
| **TDCC**（集保結算所開放資料）        | 集保戶股權分散表（各持股級距的人數與比例）           | 每週       | 用來算「千張大戶」比例的變化                           |
| **FinMind**                           | 已經整理好的台股資料                                 | —          | 開發期的備援或交叉驗證；正式上線前要確認它的再散布條款 |

## 美股：大佬追蹤

| 來源                          | 資料                                                                     | 頻率                           | 備註                                                                  |
| ----------------------------- | ------------------------------------------------------------------------ | ------------------------------ | --------------------------------------------------------------------- |
| **SEC EDGAR**                 | 13F-HR（機構季度持倉）、Form 4（內部人交易）、company tickers / CIK 對照 | 每日掃描                       | 美國政府公開資料。必須帶有聯絡資訊的 `User-Agent`，請求上限每秒 10 次 |
| **SEC 13(f) Securities List** | 13F 可申報證券清單（CUSIP、發行人）                                      | 每季                           | 輔助 CUSIP 對照                                                       |
| **OpenFIGI**（Bloomberg）     | CUSIP → ticker 對照                                                      | 依需求，結果快取在 `cusip_map` | 免費，申請 API key 可以提高額度                                       |

### 實作重點

- **13F**：從 EDGAR full-index 找出追蹤中機構的新申報，解析 information table XML；遇到修正申報（13F-HR/A）要正確合併。算出季對季差異，寫入 `us_13f_changes`。
- **Form 4**：每日掃描 Form 4 申報並解析 XML。重點訊號是交易代碼 `P`（公開市場買進），不是授予或行使選擇權，這兩種要過濾掉。
- **限制要寫在 UI 上**：13F 最多延遲 45 天，只涵蓋美股多頭部位與部分選擇權，看不到空單與海外持股。

## 之後才做

| 資料         | 候選來源                                   | 為什麼延後                      |
| ------------ | ------------------------------------------ | ------------------------------- |
| 國會議員交易 | 眾議院書記處財產申報、參議院 eFD（官方）   | 多為 PDF 或網頁，解析成本高     |
| ARK 每日交易 | ARK 官網每日持股檔案（用差異推算交易）     | 授權條款待確認                  |
| 美股 K 線    | 付費行情 API（需要允許顯示與再散布的方案） | 要花錢；大佬追蹤本身不需要 K 線 |
| 新聞         | 搜尋 API ＋ pgvector                       | 非核心功能                      |

## 不採用

- **Yahoo Finance 非官方 API**（`yfinance`、`yahoo-finance2`）：它是爬取非公開介面，條款不允許再散布，也常常因為改版就壞掉。
- **整合型商業 API 的免費方案**（Quiver、Capitol Trades、FMP、sec-api.io 等）：通常禁止再散布。要用的話，必須是有授權的付費方案。

## Provider 介面

```ts
interface Provider<T> {
  id: string;
  fetch(range: { from: string; to: string }): Promise<T[]>; // 回傳正規化後的列
}
```

台股以「日期」抓全市場（每天一個請求就能更新全部，對來源最友善）；EDGAR 以「申報 index」增量抓取。歷史資料由一次性的 backfill job 處理。
